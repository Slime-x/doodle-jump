# Space jump

Playable Link: https://slime001.itch.io/space-jump

A doodle jump like game that i wanted to build. Made with Love. 
<br>
<h2> Controls </h2>
[A],[<-] = Move Left<br>
[D], [->] = Move Right<br>
[Click] = play game<br>
<br>

<h2> How to play? </h2>

The character auto jumps. The goal of this game is to get the hightest score and reach the highest point. You should move left and right to jump onto the platform and higher from there. <br>
